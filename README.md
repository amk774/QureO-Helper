# QureO Helper

Starter project for a standalone coding-exercise helper interface (Python and Java).

## Files
- `index.html`: app interface
- `style.css`: styling
- `app.js`: initial interaction logic

This starter does not connect to QureO or read/submit questions automatically. It currently provides a simple input interface and language-specific starter code; it is not a full AI solver.

## Run
Open `index.html` in a browser.
